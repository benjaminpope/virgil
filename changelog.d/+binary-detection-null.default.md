`BinaryPipeline` `global_nsigma` (and so the `detection` check) is now the significance of the grid maximum against `n_null` (new setting, default 1000) simulated companion-free searches, not a Šidák estimate over a nominal `(2 max_sep / (λ/B))²` trials; the summary drops `n_trials` and gains `false_alarm_probability` and `n_null`. The default `detection_sigma` stays 3.0, now a false-alarm probability of 1.35e-3; runs cost `n_null` extra grid searches.
