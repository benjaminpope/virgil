- `fit` no longer reports convergence for a parameter stuck at a prior bound with the loss still falling inward. The bounded-to-unbounded map squashes the gradient to nothing there, so the gradient test passed; `fit` now also checks the first-order (KKT) sign condition in the parameter's own coordinate and returns `converged=False`, `stop="bound"`, with the offending sites in `info["bound_stall"]` and a warning. A parameter whose gradient points out of the bound (a true constrained optimum) still converges.
