- A flagged orbit cell fails a system only if it `matters` under a bound: `CellFit.log_l_sup` (the largest ln L evaluated in the cell, a lower bound on sup L, so the bound holds only if the search found the cell's top mode) replaces `log_z_upper`; the threshold is `ln(n_cells/δ)` below the best unflagged cell; `CellsResult.omitted_bound` is a diagnostic of the mass the negligible cells can hold (≤ δ). A flagged cell with no found mode now always matters (it has no bound), where before it fell back to its `ln Ẑ`. Expect more failures than before; this is intended.
