- **Behaviour change:** `error_scale(by_observable=False)` now raises `ValueError` for data with calibration gains, closure-phase offsets, a finite `prior_width` or nuisance modes, as `by_observable=True` already did: their covariance does not scale with the quoted errors, so the scalar scale was wrong. Estimate the scale on data without them. This reaches `DiskPipeline`: with `error_scale="auto"` the GP mode rescales, so a GP disk run on such data now stops in its profile stage; pass `error_scale="quoted"` there. (The B-weighted treatment of `priors=` extras stays for 0.4.3.)
