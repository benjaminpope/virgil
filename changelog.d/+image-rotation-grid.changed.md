`rotation_deg="grid"` (provisional, opt-in) for `Image`, `starting_image`, `clean`, `dirty_image` and `residual_image`: the pixel grid follows the data's uv lattice (North up without one), so fits on rotated AMI/DISCO lattices take the exact matrix transform instead of the per-point DFT. Defaults stay North up (`rotation_deg=0`). The pixel arrays of such results are then in the lattice frame (`CleanResult.rotation_deg` records it, and `restored` turns the beam); `plot_model` and the metrics (`resample`, scores) render a rotated `Image` as the sky, which resamples it bilinearly, so scores on such images can differ slightly from a North-up grid
