`apply_noise_spec` now requires `insname=` when the spec names an instrument (`OIData` records none, so the check never ran), skips closure-phase offsets on data without closure phases instead of raising, and refuses data whose `FluxSpectrum` carries nuisance modes. Also: `instrument_match` accepts a 0-d name array; the scale-marginalized surface leaves out empty extra blocks; `DifferentialPhase` keeps per-row channels when rows are uncoupled, wraps simulated draws and handles no line channels; `score_orbits` no longer profiles zero-width gain or offset groups (in the degrees of freedom or the χ²); the profiled Toeplitz gradient is zero where a ddid has no power.
