Small numerical fixes. Grid fits (`optimized_flux_grid` and friends) judge flux convergence against −½χ², not the signed normalized log likelihood, so some points' `converged` flags can change; the non-convergence warning now also reports the fraction (`CheckWarning.counts["fraction"]`). `ruffio_upperlimit` no longer returns a wrong-sign value for tiny percentiles in float32 or NaN at percentile 1. the Thiele–Innes and state-vector converters clip a face-on retrograde `inc == 180` to just below 180°, so `to_kepler` no longer raises. `linear_flux_grid` raises for data with a model-dependent covariance. `_Objective.residuals` honours `flat`/`boxed` for flat-coordinate priors, `kkt_report` swallows only the no-box error, and `build_model` rejects mismatched `params`/`values`.
