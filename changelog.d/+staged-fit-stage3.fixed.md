`fit_staged_nuisances`: `StagedFit.failed` is now also true when the stage-3 joint fit did not converge (it stopped at `max_steps` or stalled) with every nuisance inside its box and all values finite; before, only a box edge or a non-finite value failed it. The stage-3 `kkt_report` now starts from the pre-stage-2 point, so the nuisances' `grad_rel` is measured against their starting gradient and not stage 2's near-zero one, which had kept `kkt["converged"]` false on converged fits. Verdicts that change: `failed` goes from `False` to `True` for a finite, interior-nuisance fit whose stage 3 did not converge; the `kkt` nuisance `grad_rel` values (and `kkt["converged"]` where they decided it) change for every fit. A fit that converges and has no edge flag still passes. Known to need many steps: the entropy-regularized test problem converges only at about 50,000 L-BFGS-B steps.
