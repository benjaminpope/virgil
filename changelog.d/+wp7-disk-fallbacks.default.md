`DiskPipeline` changes three defaults that used to fail silently. (1) With `error_scale="rescale"` (the GP default), a missing, unreadable or factor-less profile report now raises instead of using the quoted errors. (2) A Laplace Hessian that is not positive definite gives no width for the affected parameters (`None`, where it gave 0) and no Laplace evidence for that fit; ring counts and ℓ values then compare on fewer evidences. (3) A new `laplace_pd` check warns in that case. The ridge in `regularized_inverse` (`laplace_cov`, `objective_laplace_covariance`) now applies only when the matrix is not positive definite, scaled to each diagonal entry (default 1e-10), and warns; a positive-definite Hessian is inverted exactly. Before, an absolute 1e-10 was added always.
