`DiskPipeline` no longer hides failures. A Laplace variance that is not positive gives no width (`None`, never a zero error bar) and no Laplace evidence, and a new `laplace_pd` check warns; only numerical errors are caught there, so a programming error is raised. With `error_scale="rescale"`, a missing or unusable profile report raises instead of falling back to the quoted errors. The ℓ-scan evidence and the render check lose a result only on a numerical failure. The Laplace ridge in `regularized_inverse` (and so `laplace_cov` and `objective_laplace_covariance`) is now relative to the largest Hessian diagonal entry (default 1e-10), not absolute, and warns when it decides a variance.
