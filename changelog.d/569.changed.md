The spectral-tempering factor estimate in `fit_orbit_aliases` (`aliases._temper_factors`) divides each night's block residuals by that night's empirical block scale `sqrt(χ²/ν)` before pooling across nights, and projects the whitened closure phases of 4+ station data back onto the triangle layout via `cp.basis` instead of using the unwhitened display residual. `_Proposal.log_pdf` wraps the periodic angles (`tau`, `omega`, `Omega`) to the nearest period image. Default results that change: the tempering factors `f` (hence tempered band `log_z` and `p`) for multi-night data with unequal per-night χ² or correlated 4+ station closure phases; and the cross-mode mixture `log_z_is` and its draws where modes straddle an angle's wrap. Nothing else changes (the orbit-evidence boundary handling, the `min_distance_mas` default and the null-model Occam factor are not part of this PR).
