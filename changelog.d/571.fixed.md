`read_oifits` still loads closure phases whose `OI_T3` leg coordinates are 0 or NaN when every leg has a visibility row, and otherwise checks finite coordinates against the matched legs. `write_oifits` writes partially flagged multi-wavelength closure phases (as `OI_T3` with `FLAG`) instead of refusing them. `OIData.unflagged` counts the samples of extra observables (`visamp`, `corrflux`, `visphi`, `t3amp`). `model_from_spec` rebuilds only `zodiax.Base` classes from `virgil.models`, `virgil.orbits`, `virgil.spectra` and `virgil.fields`, so a stored spec can no longer import other modules. `imaging.beam` raises when no sample is used.
