`ensemble.evidence_grid` passes its fit priors and regularizers to `log_evidence`, so its evidence now includes the free `env.flux` (`star=True`) or the `Centroid` penalty (`star=False`); the log-evidence surface, and so the Gaussian-process members `gp_members` keeps, can change. `ensemble.combine` on `star=False` data with no phase observables (no closure phases and no differential phases) also tries each member's 180° point inversion when registering it, so members the data cannot tell apart from their inverted images are no longer left in the wrong orientation. `limits.absil_limits` and `limits.injection_limits` evaluate the null at the first grid coordinates instead of zeros (the same as `detection_statistics`), which changes nothing for a model that is valid at zero separation. `StarPipeline` reports sampler failures (R-hat, ESS, divergences, prior bounds) of a model it did not select as `warn` checks that name the model, where they were `fail`; the selected model's failures stay `fail` and `summary["posterior"]` still reports the worst chain health over all models.
