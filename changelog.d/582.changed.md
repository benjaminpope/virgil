Pipeline checks no longer hide failures. A `divergences` check that fails stays `fail` when the wall probe finds hard likelihood walls (the walls are named in the message as a probable cause; the `exposed` threshold now only decides whether the walls are named), and the failing r̂, ESS and divergence checks of a model that is not selected stay `fail` instead of becoming `warn`, even when the selected model only warns. Runs that used to report `warn` for these now report `fail`.
