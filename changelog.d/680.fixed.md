`vis_mode="logamp"` (and `"amp"` from V²) no longer floors visibilities at their own error: points with V² or |V| ≤ 0 are excluded with one counted warning (an error for data with an operator, `vis_mat`), and points with 0 < V² < σ are kept at their own value with first-order error and a counted warning. `vis_mode="v2"` from |V| uses the exact standard deviation σ√(4V² + 2σ²) of a squared Gaussian amplitude (not a floor; it stays finite at |V| = 0) and warns for |V| < σ. Fits on low-SNR data with these modes change.
