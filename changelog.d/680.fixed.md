`vis_mode="logamp"` (and `"amp"` from V²) no longer floors visibilities at their own error: points with V² or |V| ≤ 0 are excluded with one counted warning, points with 0 < V² < σ are kept at their own value with first-order error and a warning, and `vis_mode="v2"` from |V| uses the first-order error 2|V|σ. Fits on low-SNR data with these modes change; data with an operator (`vis_mat`) and V² ≤ 0 now raise.
