`fit_staged_nuisances`: `StagedFit.failed` is now also true when the stage-3 joint fit did not converge (it stopped at `max_steps` or stalled) with every nuisance inside its box and all values finite; before, only a box edge or a non-finite value failed it. The stage-3 `kkt_report` now starts from the staged fit's own start (the `init` image and `full.defaults()` for the nuisances) instead of the stage-3 starting point (stage-1 image, stage-2 nuisances), whose near-zero nuisance gradients inflated `grad_rel` (~2e7 on a converged fit). Verdicts that change: `failed` goes from `False` to `True` for a finite, interior-nuisance fit whose stage 3 did not converge (for example the short `imaging_rml` tutorial run); the nuisance `grad_rel` values and the image block's `kkt_rel`, `want_grow` and linear-certificate scale change for every fit, so `kkt["converged"]` can flip from either block. A fit that converges and has no edge flag still passes.
