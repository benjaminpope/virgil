Ensemble and imaging defaults (integrity pass): `EnsembleSpec.max_chi2_red` is deprecated (the χ² cut is relative to the best member, `chi2_ratio`; default `None`, no absolute cut as before). `ImagingPipeline(grid_growths=None)` now follows the engine's 3 growths (was 2). `BinaryPipeline` `flux_range` default is `[1e-5, 1.0]` (was `[1e-5, 0.5]`, which excluded companions brighter than half the primary). The ensemble weight ranges are labelled as set on the SPIE contest bench; the `error_scale`, `oversample`, field and start differences between pipeline and engine are documented as deliberate.
