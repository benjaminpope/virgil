# `virgil.smc`

Adaptive tempered sequential Monte Carlo on BlackJAX: the evidence and
posterior particles of a flat-vector model, and the evidence ratio between two
likelihoods. See [`virgil.smc`][virgil.smc] for the algorithm and its
references.
